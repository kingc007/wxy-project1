## Conflicts
- CONFLICTING (address->BBL): PLUTO row `{"bbl":"1020610054.00000000","address":"452 WEST 147 STREET","zonedist1":"R7A","zonedist2":"R6A","splitzone":true}` (26v2) vs GeoSearch for "452 West 147 Street, Manhattan" -> `"addendum":{"pad":{"bbl":"1020610051"` (PAD 26c). PLUTO's own row for bbl 1020610051 is `"address":"450 WEST 147 STREET"` (zonedist1 R7A, histdist "Hamilton Heights / Sugar Hill Historic District", 33,220 sf bldg). This lot was therefore REJECTED from the evaluation set and replaced by 196 East 3 Street (lot 6). Lesson: address-lookup can mismatch PLUTO for multi-address/range lots; the pipeline must not assume a 1:1 match.
