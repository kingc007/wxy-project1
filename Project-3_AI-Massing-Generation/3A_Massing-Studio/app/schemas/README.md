# schemas/

`zoning-envelope.schema.json` is a **generated copy** of the canonical schema (schemaVersion 1.0.0, owned by Project 1),
which lives in `Project-3_AI-Massing-Generation/shared/massing/data/` (package `@wxy/massing`).
Do not edit it. `npm run copy-schema` (also run by predev, prebuild and postinstall) refreshes it.

The SAMPLE envelopes and the SAMPLE Fort Greene context now live in the same shared package
(`@wxy/massing/data/samples/*`, `@wxy/massing/data/context-fort-greene.json`); `npm run samples` is run there.
